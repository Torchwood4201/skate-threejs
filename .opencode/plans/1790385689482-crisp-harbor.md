# Skate-3-flavoured browser game — whole-game milestone plan

## Goal
Build a Skate-3-inspired skateboarding game inside the existing Three.js game at `/home/runner/work/skate-threejs/skate-threejs`, using the two linked repos as **research reference only** — not as code to copy or assets to ship.

## Hard constraints (do not negotiate in milestones)
- `mchughalex/skate3recomp` is a native C++/CMake recompilation (D3D12/Vulkan) that needs a legally owned Xbox 360 ISO + title update. There is no web/Three.js module to import; its code cannot run in a browser, especially on phones.
- `SK8-ENGINE/skate-3-rust-engine` is Rust + Bevy under GPL-3.0-only and needs converted retail assets in a `data/` folder, Windows + gamepad. Copying its code would force this game GPL too. Use its public docs/ideas (flick input, grinds, off-board, difficulty, `.skate` map concepts), never its code or EA assets.
- No EA retail files, ISO extraction, or converted `data/` assets enter this repo. All art/audio/character/UI in this game comes from `npx genex …` or existing procedural stand-ins.
- Existing guarantees stay: desktop tiers frozen (prove by structure + GL census, not PNG — metering noise floor ~8%), phone Auto → `phone-low` 30fps, touch chunk stays separate, `fallLine`/`pushBlocked`/lip+wall probes do not regress, no debug-only flags (only `?genex_local_test=1`).

## What we take from each repo (ideas, re-implemented in TypeScript)
- From recomp: control map (left stick / right stick roles, LT/RT, LB/RB, stick-click, Back/Start), keyboard-emulation table, native-renderer lesson (one shadow rasterisation per frame — already done in `look.ts`).
- From rust engine: flick-style right-stick trick throws, off-board movement concept, difficulty settings, grind/trick parity notes, map-switching without restart (`goToSpot()` already does this).

## Milestones (coordinated, in order; parallel only where noted)

### M16 — Flick + board feel (movement lane, serial first) — LANDED 2026-10-13
Re-implement Skate-3-style input feel without changing key bindings players know:
- `SkateInputSource.flickTrick()` runs the same `press()` a key runs (flick/key byte-identical, item 9 in `input-matrix.mjs`); phone FLICK swipe island in the touch layer (up pops, right kicks, left heels, down shoves); no mouse gesture — pointer lock owns the mouse.
- Touch: `src/ui/touch-controls.ts` (gate) + `src/controllers/touch/skate-touch-layer.ts` (layer); keyboard: `src/skate/input.ts`; feel: `src/skate/skate-model.ts` constants only.
- Done when: flick and button paths produce identical trick + landing results at 30/60/144fps; A/← = screen-LEFT, D/→ = screen-RIGHT verified by riding, not reading.

### M17 — Gamepad (controller lane, after M16) — LANDED 2026-10-13, SUPERSEDED by M18's PDF remap (see DESIGN.md milestone 18)
Native pad support so no mapper is needed (XMapper pad→keys keeps working untouched — it arrives as key events and never meets this code):
- New `src/controllers/gamepad/skate-gamepad.ts` polled once per frame in `main.ts` before `takeReset()`/`consume()`; feeds the same three doors (left stick → `touchSteer`, push/brake through the 0.45/0.30 gate, buttons as holds/latches, right stick throws via `flickTrick` with re-arm, Start → `pressPause`/`takePausePressed` latch, Back → reset). Right stick stays the trick stick, so the mouse keeps the camera with nothing to fight. Disconnect drops only pad-held codes silently (a yanked plug stands him up, never pops him); no pad connected is one falsy read per frame.
- Done when: pad/key byte-identical at 30/60/144fps (item 10 in `input-matrix.mjs`, 10/10 watched failing).

### M18 — ZIP PARKS + PDF CONTROLS (2026-10-13) — LANDED
- Parks: `public/parks/Skateparks/` (3 GLBs as shipped) + `src/world/parks.ts` (raycast SurfaceProvider, ~70 m normalise, street sky); registered in `world/maps.ts`; audio→street in `main.ts`. V1: no grind lines, no walls (softEdge 55), street bed.
- Controls: gamepad rewritten to the PDF Flick-it map (only it); touch FLICK sides flipped to match (left=kick); keyboard unchanged as aliases; pad rows on Controls screen. Open: nose manual has no pad path; X/R3 bail is reset.
- Done when: item 10 (21 PDF checks) green at 30/60/144, all watched failing; parks build headless; `tsc` 0, `vite build` clean.

### M19 — Trick / grind / manual parity (gameplay lane, serial after M18) — CONSUMED by DESIGN M20 (2026-10-13)
Plan asked: flip flavours, square-entry slides, manual holds, combo bank unchanged. Landed instead in the mash-up: treflip + Tailgrab + grind-commit + revert + charged ollie; square-entry/manal-holds pre-existing kept. The `pot×min(links,10)` clause below is STRUCK — DESIGN M20 pins the THPS ×5 cap and `integration-check.mjs` asserts it.
- Extend `src/skate/tricks.ts` + `src/skate/grind.ts` + manual balance in `skate-model.ts` toward Skate-3 vocabulary (flip flavours, square-entry slides, manual holds), reusing existing `clean` (flip≥1, off-square≤60°, no held grab at touchdown) and `Grinder` catch bands. No new physics engine; tune constants.
- Animation: map new intents to existing `HAND_CLIPS`/`POSTURES` in `src/skate/skater-anim.ts`, board rotation in `src/skate/skater-rig.ts`.
- Done when: `grind-auto`, `hold-check`, `anim-check`, `input-matrix` harnesses pass; combo bank (`pot×min(links,5)` per the struck clause above).

### M20 — World / spots (world lane, parallel with M21 after M18)
- Keep street block live (`src/world/spot.ts` solids + `src/world/field.ts` sun/fog/shadow). Add ONE new skateable spot in the `spillway.ts` shape (fog, sun+hemi, `SurfaceProvider`, rails/placements), register in `src/world/maps.ts`, dress via `props.ts` pattern with procedural fallbacks + KTX2 rungs. No retail map data.
- Done when: `goToSpot()` swaps with no leak (`disposeSky`), phone census stays <300MB broad, `decal-gap`/`collide-sweep` clean.

### M21 — Rider / audio (character lane, parallel with M20 after M18)
- Rider stays the game's own generated character (`npx genex character` → controller); VRM only as recorded fallback. Add Skate-3-style push/off-board idle flavour via existing hand-clip + posture path, not new rigs.
- Audio stays `HTMLAudioElement` beds (`src/audio.ts`); add flick/pop/grind voices via `npx genex sfx`, one looping track via `npx genex music` under settings sliders.
- Done when: idle/push/ollie/grind/bail read correctly in a gameplay capture; no new body ships without preview.

### M22 — HUD / menus / mobile + quality (UI lane, serial last)
- HUD stays restrained CSS (`src/ui/hud.ts`): combo, spin, balance, run clock, results with local best. Menus: title/pause/settings/leaderboard screens; settings keeps Auto/Low/Med/High + difficulty (rust-engine-inspired: catch windows, balance rates) wired to `Grinder`/manual constants.
- Mobile: keep gate + chunk split, portrait overlay, `touch-action:none`, viewport-fit; quality: tier/governor/KTX2/aniso/shadow-cadence untouched unless a census earns it.
- Done when: desktop DOM/listeners unchanged, phone chunk still split, Escape pauses, loader shows game.

### M23 — Stabilise + preview (director, serial)
- `tsc` 0, `vite build` clean, ride + perf harnesses green, one smoke capture per milestone in `?genex_local_test=1` with real gameplay screenshot, then `npx genex preview` + page link. Never localhost/file path as the player's link.
